# Security log Parser & Threat Analyzer:
A lightweight python CLI security tool designed to parse web server access logs,detect suspicious activites (brute-force or directory scanning) and flag high-risk ip addresses.
 
## Features:
- **ANSI Color-Coded Output:** Green, yellow, and red terminal alerts for easier and rapid screening.

- **Dynamic Failure Thresholds:** Automatically flags IPs exceeding configurable failure thresholds. 

- **Real-Time Inspection:** Live progress tracking and line-by-line log analysis.

## Requirements:

- Python 3.x

## Usage:
- Run the analyzer directly from your terminal.
```bash
python3 log_parser.py 
```
